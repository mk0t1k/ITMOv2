# Few-shot

- Артефакт Практики 1: [`tests_load.md`](../practice_01/tests_load.md)
- Что хотим улучшить: 10 RPS / p95 / 1% без CASE.md; одиночный 413 выдан за нагрузку; таблица спорит с «пока не нужно»

## Примеры

### Хороший результат

```
| Конкурентный отказ API-1 | 20 параллельных POST /api/reviews, diff длиной 20001, 1 минута | 100% HTTP 413; 0 ответов 500; очередь не превращает отказ в таймаут LLM | Доля 413, доля 500, max in-flight | API-1 (CASE.md): diff > 20000 → HTTP 413 |
| Конкурентный REL-1 | 10 параллельных POST с корректным diff; mock LLM sleep > 10с | Каждый вызов LLM обрывается на 10с; ответ в формате OUT-1, не HTTP 500 | Доля контролируемых ответов; факт timeout=10с | REL-1 (CASE.md): timeout 10с, ошибка → контролируемый ответ |
```

### Плохой результат

```
| Серия POST с средними diff | 10 RPS, 5 минут | p95 < 500ms без LLM-задержек; error rate < 1% | latency | API-1/REL-1 |
| Oversized diff отказ | 2 RPS, 1 минута | 100% HTTP 413 | доля 413 | API-1 |
```
