Критерий 1 // 5 баллов

Настроенная среда агента и обоснование подключений

Зачем нужны выбранные подключения?
  • AGENTS.md: Жесткий контракт архитектуры, запрет переходить к Фиче Б до верификации Фичи А, соблюдение кодстайла Three.js (shallowRef, очистка ресурсов).
  • Skill threejs-animation: Предотвращает частые галлюцинации LLM по работе с AnimationMixer, AnimationClip и вызовом update(delta).
  • MCP solar-ephemeris: Обеспечивает модель достоверными физическими константами (масса, AU, периоды) без выдумывания "примерных" чисел.
  • Hook check-after-edit.js: Выполняет scripts/check.sh при каждом изменении файлов агентом и передает вывод компилятора в контекст.

🪐 ФАЗА 1: Фича А — 3D-Сцена и Орбиты
  • Холст WebGL: Адаптивный рендерер с ACESFilmicToneMapping, ResizeObserver.

Критерий 2 // 2 балла

Skill threejs-animation: Разбор и интеграция

Устройство скилла (Разбор студента)

«Скилл threejs-animation структурирует работу с официальной системой ключевых кадров Three.js, связывая AnimationClip, треки дорожек (VectorKeyframeTrack) и диспетчер AnimationMixer. Он задает жесткое правило обязательного обновления миксера дельтой времени (mixer.update(delta)) в основном цикле рендеринга и следит за правильными путями PropertyBinding. Использование скилла предотвратило типичную ошибку замирания кастомной анимации свечения Солнца при интеграции с реактивным циклом Vue 3.»

  • Каталог: .opencode/skills/threejs-animation/
  • Триггеры скилла: AnimationMixer, AnimationClip, KeyframeTrack, crossFade.
  • Применение в коде: SolarScene.setupSunPulseAnimation().
Реализация в проекте (SolarScene.ts)
// Настройка пульсации солнечной короны через AnimationMixer private setupSunPulseAnimation(): void { const times = [0, 1.5, 3] const values = [ 1.0, 1.0, 1.0, 1.12, 1.12, 1.12, 1.0, 1.0, 1.0 ] const track = new THREE.VectorKeyframeTrack( 'SunGlowMesh.scale', times, values ) const clip = new THREE.AnimationClip('SunPulseClip', 3, [track]) const action = this.animationMixer.clipAction(clip) action.setLoop(THREE.LoopRepeat, Infinity) action.play() } // В цикле requestAnimationFrame: if (this.animationMixer) { this.animationMixer.update(delta) }
Критерий 3 // 2 балла

Собственный MCP: solar-ephemeris-mcp

Архитектура и доступные Tools
  • Стек: Node.js, @modelcontextprotocol/sdk, TypeScript, stdio transport.
  • get_body_info: Получение физических характеристик тела (масса, радиус, период, факты).
  • compute_kepler_position: Расчет 3D-позиции (x, y, z) тела с учетом большой полуоси, эксцентриситета и наклона орбиты.
  • validate_orbit_timing: Проверка физической кинематики по 3-му закону Кеплера (a³ / T² ≈ 1).
  • get_scaled_system_data: Генерация масштабных коэффициентов для Three.js.
  • Ресурсы MCP: Схемы astronomy://bodies/{id} с полным научным профилем.
Конфигурация в opencode.json
{ "$schema": "https://opencode.ai/config.json", "mcp": { "servers": { "context7": { "type": "remote", "url": "https://mcp.context7.com/mcp" }, "solar-ephemeris": { "type": "local", "command": "node", "args": ["mcp-server/dist/index.js"], "disabled": false } } } }

Сервер локально компилируется из TypeScript в JavaScript и запускается OpenCode в режиме stdio.

Критерий 1 & Hook // Подтверждение качества

Единый раннер проверок и плагин check-after-edit

Плагин .opencode/plugins/check-after-edit.js

Перехватывает завершение вызова инструментов модификации кода (write_to_file, edit_file, replace_file_content) и автоматически запускает раннер:

export default async function (ctx) { ctx.tool.hook("execute.after", async (input, output) => { const editTools = ["write_to_file", "replace_file_content", "edit_file"]; if (editTools.includes(input.tool)) { const res = await ctx.exec("sh scripts/check.sh"); return { ...output, checkResult: res.stdout || res.stderr, }; } return output; }); }
