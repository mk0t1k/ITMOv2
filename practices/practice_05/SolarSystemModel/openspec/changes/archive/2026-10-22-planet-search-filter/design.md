# Design

## Context

В текущей версии `CanvasViewport.vue` планетная навигация представлена списком кнопок `.quick-nav` для Солнца и планет (`SUN_DATA`, `PLANETS_DATA`). Переход к объекту выполняется методом `selectFromList(body)`, который вызывает `solarSceneRef.value.selectBody(body)` и устанавливает `selectedBody.value = body`.
Архитектурные ограничения проекта (согласно `docs/style-guide.md` и `AGENTS.md`):
- Three.js сцена не должна пересоздаваться или оборачиваться в глубокий `reactive()`.
- Исходные данные берутся строго из `src/data/celestialBodies.ts`.
- Анимационный цикл и контроллеры времени (`TimeControls.vue`) должны оставаться независимыми от поисковых операций в UI.

## Goals / Non-Goals

**Goals:**
- Интегрировать поле ввода поиска небесных тел в UI верхнего бара (`CanvasViewport.vue` или дочерний компонент).
- Обеспечить мгновенную регистронезависимую фильтрацию по обоим полям: `name` (EN) и `russianName` (RU).
- Поддержать выбор по Enter: если есть результаты, нажатие Enter в поле поиска выбирает первое совпадение, выполняя стандартный переход камеры и открытие карточки (`PlanetCard.vue`).
- Поддержать сброс поиска клавишей Escape или кнопкой очистки.
- Обеспечить непрерывность анимационного цикла Three.js и отзывчивость `TimeControls.vue`.

**Non-Goals:**
- Добавление сторонних библиотек нечеткого поиска (fuzzy search). Достаточно нативного `includes()` с нормализацией регистра и триммингом.
- Изменение физической модели орбит или формата данных небесных тел в `celestialBodies.ts`.

## Decisions

1. **Размещение компонента и состояние поиска**:
   - *Решение*: Вынести логику фильтрации в чистую функцию-хелпер или инкапсулировать реактивное состояние в верхней навигации `CanvasViewport.vue` / выделенном модуле `src/components/CelestialSearch.vue`.
   - *Альтернативы*: Использовать стороннюю шину событий или глобальное хранилище Pinia — отклонено как избыточное усложнение для локального UI-поиска.
2. **Алгоритм поиска**:
   - *Решение*: Нормализовать поисковый запрос (`query.trim().toLowerCase()`) и фильтровать список из Солнца и планет:
     `item.russianName.toLowerCase().includes(q) || item.name.toLowerCase().includes(q)`.
   - *Альтернативы*: RegEx со сложными правилами — излишне и может приводить к ошибкам синтаксиса при спецсимволах.
3. **Автофокус по Enter**:
   - *Решение*: Обработчик `@keydown.enter` на `<input>`: если отфильтрованный массив `filteredBodies.length > 0`, вызывается `selectBody(filteredBodies[0])`.
4. **Взаимодействие со сценой**:
   - *Решение*: Вызов существующего метода `SolarScene.selectBody(body)`, который уже корректно запускает анимацию фокуса камеры без остановки анимационного цикла (`requestAnimationFrame`).

## Risks / Trade-offs

- [Risk] Перехват событий клавиатуры (например, Enter или пробел) может конфликтовать с управлением сценой.
  → Mitigation: Обработчики клавиатуры вешаются строго на элемент `<input>`, с использованием `event.stopPropagation()` при необходимости.
- [Risk] Переполнение верхнего бара на небольших разрешениях экрана.
  → Mitigation: Использовать адаптивную верстку (`@media (max-width: 992px)` / flex-wrap) в Sci-Fi стилистике с сохранением доступности на мобильных устройствах.
