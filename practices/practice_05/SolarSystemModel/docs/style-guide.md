# Style Guide проекта Solar System

1. **Изоляция Three.js:** Экземпляры `THREE.Scene`, `Mesh`, `Renderer` и `Camera` никогда не оборачиваются в `ref()` или `reactive()`. Используется `shallowRef()` или чистый класс сцены.
2. **Очистка ресурсов:** Все геометрии, материалы и текстуры должны явно уничтожаться через `.dispose()` при размонтировании (`onUnmounted`).
3. **Единый источник констант:** Радиусы планет, масштабы и периоды берутся строго из `src/data/celestialBodies.ts`.
4. **Не ослаблять раннер:** Запрещено отключать проверки типов в `scripts/check.sh` ради прохождения тестов.
