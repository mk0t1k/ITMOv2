## ФАЗА 1: Фича А — Базовая 3D-сцена и Орбитальная Анимация

### 1.1. Назначение
Создать функциональный каркас приложения на Vue 3, инициализировать Three.js-сцену, отобразить Солнце и 8 основных планет, настроить орбитальное движение и базовое управление камерой.

### 1.2. Функциональные требования
1. **Инициализация 3D сцены (`SolarScene.ts`, `CanvasViewport.vue`):**
   - Холст занимает 100% экрана, адаптируется под `resize` окна.
   - Источник света `PointLight` расположен в центре Солнца (с затуханием) + мягкий `AmbientLight`.
   - Звёздный фон (сгенерированное звёздное поле через `THREE.Points`).
2. **Небесные тела (`src/data/celestialBodies.ts`):**
   - Солнце в координатах `(0, 0, 0)` с лёгким эффектом свечения.
   - 8 планет: Меркурий, Венера, Земля, Марс, Юпитер, Сатурн, Уран, Нептун.
   - Для Сатурна — геометрия колец (`RingGeometry`).
   - Визуальные траектории орбит (`LineLoop` или `BufferGeometry`).
3. **Кинематика и движение:**
   - Движение по орбитам в плоскости XZ на основе дельты времени: `угол += (speed / period) * delta`.
   - Вращение планет вокруг собственной оси (axial rotation).
   - Сохранение относительного порядка орбитальных периодов (Меркурий быстрее всех, Нептун медленнее всех).
4. **Управление:**
   - Камера с `OrbitControls` (вращение, панорамирование, масштабирование колесиком).
   - Минималистичная плавающая кнопка «Старт / Пауза» симуляции на Vue.

### 1.3. Критерии приёмки Фичи А
- `npm run build` и `npm run typecheck` проходят без ошибок.
- В браузере нет ошибок WebGL, все 8 планет отображаются и корректно движутся по своим орбитам.
- Частота кадров (FPS) стабильно $\ge 50$ кадров/с.

## ФАЗА 2: Фича Б — Интерактивность, Инфо-карточки и Контроль Времени

### 2.1. Назначение
Добавить пользовательский интерфейс для взаимодействия с планетами: выбор кликом, фокус камеры, просмотр характеристик и управление ходом времени.

### 2.2. Функциональные требования
1. **Интерактивный выбор (Raycasting):**
   - Наведение мыши: курсор меняется на pointer, появляется компактный тултип с названием объекта.
   - Клик по планете переводит систему в режим детального просмотра этой планеты.
2. **Кинематографичный фокус камеры:**
   - Плавное перемещение камеры (`lerp` / кватернионы / TWEEN) к выбранной планете на удобное расстояние обзора.
   - Камера привязывается к движущейся планете и летит вместе с ней по орбите.
   - Кнопка «Общий вид» (Reset View) плавно возвращает камеру в исходное положение.
3. **Панель характеристик (`PlanetCard.vue`):**
   - Боковая шторка (Glassmorphism) с анимацией появления при клике.
   - Содержит:
     - Название и тип (планета земной группы / газовый гигант / ледяной гигант).
     - Реальный радиус, масса, дистанция от Солнца, период обращения.
     - 1-2 интересных научных факта.
4. **Панель времени и режимов (`TimeControls.vue`):**
   - Регулировка скорости симуляции (0.25x, 1x, 2x, 10x, 50x).
   - Переключение масштабирования: «Визуальный масштаб» (планеты увеличены для читаемости) и «Реалистичные пропорции».

### 2.3. Критерии приёмки Фичи Б
- Клик по любой планете корректно триггерит анимацию камеры и отображает карточку с её данными.
- Ползунок времени корректно ускоряет анимацию без рывков.
- Все модули покрыты юнит-тестами (`tests/orbit_math.spec.ts`).
